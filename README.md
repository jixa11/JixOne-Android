# JixOne اندروید 🎵

پخش‌کننده‌ی موسیقی یوتیوب برای ایران — نیتیو، سریع و با تم‌های ایرانی.

JixOne اندروید بر پایه‌ی [OuterTune](https://github.com/OuterTune/OuterTune) ساخته شده و تم‌های محبوب اپ وب JixOne را به اندروید آورده است.

## ✨ تم‌های ایرانی

چهار تم میراثی JixOne با پالت‌های کامل متریال ۳ (ساخته‌شده با `material-color-utilities`):

| تم | توصیف |
|----|-------|
| **فرش ایرانی** | طلای زعفرانی روی نیلی عمیق فرش کاشان |
| **کاشی اصفهان** | فیروزه و لاجورد کاشی‌کاری مساجد، در شب |
| **درفش کاویانی** | پرچن شاهی: زر، بنفش و سرخ بر زمینه‌ی بادمجانی |
| **کوروش هخامنشی** | زر تخت‌جمشید و لاجورد بر پاپیروس (تم روشن) |

از مسیر: **تنظیمات ← ظاهر ← تم‌های ایرانی JixOne**

## 🔄 بررسی به‌روزرسانی

در **تنظیمات ← درباره**، اپ به‌صورت خودکار آخرین نسخه را از [صفحه‌ی Releases](https://github.com/jixa11/JixOne-Android/releases) چک می‌کند و دکمه‌ی دانلود مستقیم APK نشان می‌دهد.

## 📥 نصب

APK آماده را از [Releases](https://github.com/jixa11/JixOne-Android/releases) دانلود کنید — برای نصب، اجازه‌ی «منابع ناشناس» لازم است.

ویژگی‌های کامل (ورود با حساب گوگل، دانلود آفلاین، پخش پس‌زمینه، لیrics و…) همگی از OuterTune به ارث رسیده‌اند.

## 🔑 ورود به حساب

تنظیمات ← حساب ← ورود — با حساب گوگل خود وارد شوید تا پخش و دانلود از هر IP و بدون محدودیت ربات کار کند.

# JixOne for Android 🎵 (English)

A YouTube Music client for Persia — native, fast, and dressed in Iranian themes.

JixOne Android is built on [OuterTune](https://github.com/OuterTune/OuterTune) and brings the beloved JixOne web-app themes to Android.

## ✨ Persian heritage themes

Four JixOne themes with full Material 3 palettes (generated through `material-color-utilities`):

| Theme | Description |
|-------|-------------|
| **Persian Carpet** | Saffron gold on the deep indigo of a Kashan carpet |
| **Isfahan Tile** | Turquoise and lapis of mosque tilework, by night |
| **Kaviani Banner** | The royal standard: gold, violet and crimson on plum |
| **Cyrus the Great** | Persepolis gold and lapis on papyrus (light theme) |

Find them under **Settings → Appearance → JixOne themes**.

## 🔄 Update check

**Settings → About** auto-checks the latest release from the [Releases page](https://github.com/jixa11/JixOne-Android/releases) and offers a direct APK download.

## 📥 Install

Grab the APK from [Releases](https://github.com/jixa11/JixOne-Android/releases) — allow "unknown sources" when prompted.

All the inherited OuterTune features are here: Google account login, offline downloads, background playback, lyrics, and more.

## 🔑 Sign in

Settings → Account → Sign in with your Google account so playback and downloads work from any IP without bot-check limits.

## 🛠 Build from source

```bash
git clone --recurse-submodules https://github.com/jixa11/JixOne-Android.git
cd JixOne-Android
./gradlew assembleCoreRelease
```

Requires JDK 21 and Android SDK 36.
